User Guide
==========

The user guide explains what the quadrilateralized spherical cube is, what the
two classes in this package do with it, and how to choose between the options
they give you. It assumes you have run through :doc:`../getting_started`.

If you would rather learn from complete problems than from a reference, go
straight to the :doc:`worked examples <../examples/index>`; each one links back
here for the ideas it uses.
